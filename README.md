# الاتحاد العربي لحماية حقوق الملكية الفكرية (AUIPR)
### Official Web Portal & Multi-Branch Management System

بوابة إلكترونية رسمية متكاملة للاتحاد العربي لحماية حقوق الملكية الفكرية (منظمة عربية تعمل في نطاق مجلس الوحدة الاقتصادية العربية - جامعة الدول العربية).

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **الواجهة الأمامية (Frontend):**
  * HTML5 الدلالي النظيف والمتجاوب بالكامل مع مختلف الشاشات.
  * CSS3 حديث بنظام Grid & Flexbox، مع دعم WebP للأداء الفائق وسرعة التحميل.
  * Vanilla JavaScript (ES6+) خفيف وسريع بدون أطر عمل ثقيلة.
* **الخوادم السحابية (Backend / Serverless):**
  * **Netlify Serverless Functions** (`netlify/functions/news.js`) للتعامل مع العمليات الخلفية وواجهات الـ API.
* **قاعدة البيانات (Database):**
  * **MongoDB Atlas** السحابية لتخزين وإدارة الأخبار وسجلات الإدارة والتحكم بالفروع.
* **المراسلات والاستمارات (Forms):**
  * Web3Forms API لاستقبال طلبات التسجيل والمشاركات مباشرة على البريد الرسمي.

## 🚀 التشغيل والإعداد المحلي (Local Setup)

### 1. المتطلبات الأساسية
* تثبيت بيئة [Node.js](https://nodejs.org/) (الإصدار 18 أو أحدث).

### 2. تثبيت الحزم
```bash
npm install
```

### 3. إعداد متغيرات البيئة
انسخ ملف `.env.example` إلى `.env` وقم بإدخال بيانات الاتصال بقاعدة البيانات:
```bash
cp .env.example .env
```

### 4. تشغيل الموقع محلياً
لتشغيل الموقع مع دعم Netlify Functions محلياً:
```bash
npm run dev
# أو
npx netlify dev
```

## 🌐 نظام إدارة الفروع والممثليات الإقليمية (Multi-Branch System)

يدعم الموقع التبديل التلقائي للهوية والمحتوى حسب النطاق أو الفرع:
1. **المقر الرئيسي (جمهورية مصر العربية):** النطاق الأساسي `auipr.org`.
2. **فرع المملكة الأردنية الهاشمية:** النطاق الفرعي `jordan.auipr.org` أو المعامل `?branch=jordan`.
3. **ممثلية الجمهورية اللبنانية:** النطاق الفرعي `lebanon.auipr.org` أو المعامل `?branch=lebanon`.

## 🔐 لوحة الإدارة والصلاحيات (Admin Portal & RBAC)

الوصول إلى لوحة التحكم عبر: `/admin.html`

* **المشرف العام (Super Admin - `admin_general`):**
  * إدارة ونشر الأخبار لجميع الفروع.
  * التحكم في تجميد أو تفعيل صلاحيات الفروع الإقليمية.
  * الاطلاع على سجلات التدقيق الأمني (Audit Logs).
* **مشرف فرع الأردن (`admin_jordan`):**
  * إدارة ونشر أخبار فرع الأردن والمقر الرئيسي.
* **مشرف فرع لبنان (`admin_lebanon`):**
  * إدارة ونشر أخبار فرع لبنان حصراً.

## 🚢 النشر (Deployment)

المشروع جاهز ومُهيّأ تماماً للنشر على منصة **Netlify**:
* عند ربط المستودع، سيقوم Netlify تلقائياً بالتعرف على ملف `netlify.toml` وتشغيل دوال `netlify/functions` وتطبيق رؤوس الأمان (Security Headers) وإعدادات التخزين المؤقت (Cache-Control).
